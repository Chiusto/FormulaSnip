# 公式快截 FormulaSnip

> 借鉴 Snipaste 交互的「截屏 → 公式识别」小工具：**按 F1 框选屏幕上的公式区域，交给「你自己的模型」后台识别——屏幕侧边只出现一个迷你小窗不打断工作，完成后自动复制并提示；点开小窗即可查看、编辑后再复制；支持贴图到桌面。**

- 模型完全自定义：填写任意 **OpenAI 兼容接口** 的 `base_url + api_key + model` 即可（OpenAI、通义千问 VL、智谱 GLM-4V、硅基流动、Ollama 本地……都能用）。
- 提示词完全自定义：识别行为由你写的提示词决定（数学公式、手写公式、题目解答、图表描述……都行）。
- 截图与识别数据只发送到你配置的服务，不经过任何第三方中转。

## 界面一览（使用流程）

```
常驻系统托盘 ──按 F1 / 双击托盘──▶ 全屏选区 ──回车/双击确认──▶ 屏幕侧边迷你窗（识别中）
   ▲                                                        │
   │                              完成后自动复制 + 托盘气泡提示
   │                                                        │ 左键点开（可选）
   │                                                        ▼
   └────────── 结果窗口（查看 / 编辑 / 复制 / 预览 / 贴到桌面）──────────┘
```

| 按键 / 操作 | 作用 |
| --- | --- |
| `F1`（全局） | 开始截图（Windows 全局热键；**若 F1 被其它程序占用会自动改注册备用键 `F2` → `Ctrl+Shift+X` 并在气泡中提示**，实际生效键显示在托盘菜单里；全部失败时仍可用托盘菜单"截图识别"触发） |
| `F3`（全局） | 贴图：剪贴板有**图片**直接贴到桌面；有**文字**渲染成文字贴图（白底黑字、自动换行、超长截断）。贴图可拖动、滚轮缩放、右键菜单复制/另存/关闭；文字贴图双击或菜单「复制文字」取回原文。备用键 `F4` → `Ctrl+Shift+V` |
| 左键拖拽 | 框选区域 |
| 拖拽选区边缘/四角 | 缩放选区 |
| 拖拽选区内部 | 移动选区 |
| 方向键 / `Shift`+方向键 | 选区微调（1px / 10px） |
| `Enter` / 双击 | 确认选区并识别 |
| `Esc` | 取消选区 / 退出截图 |

**选区工具条（同 Snipaste）**：松开鼠标确定选区后，选区右下角自动浮现工具条。按钮为白色线性图标（QPainter 现画、无外部资源），悬停显示文字提示：

| 图标 | 功能 |
| --- | --- |
| 鼠标箭头 | 选择：切回选区调整模式（拖动移动 / 拉边框缩放，快捷键 `S`） |
| 铅笔 | 画笔：按住左键在选区内涂写（快捷键 `P`） |
| 矩形 | 矩形框选标注（快捷键 `R`） |
| 椭圆 | 椭圆标注（快捷键 `E`） |
| 箭头 | 箭头指示（快捷键 `A`） |
| 圆形色块 ×5 | 标注颜色：红 / 黄 / 绿 / 蓝 / 白 |
| ↶ | 撤销上一步标注（`Ctrl+Z`） |
| 垃圾桶 | 清空全部标注 |
| `ƒx` | 识别公式：确认选区，调用你配置的模型识别（等同回车/双击） |
| 文档 | 提取信息：提取选区全部多模态信息（文字/公式/表格/图表）为结构化文本并复制，供无视觉模型作为视觉输入 |
| 双层矩形 | 复制：选区图片直接进剪贴板（**含标注**），Ctrl+V 即可粘贴 |

| `✕` | 退出截图（遮罩关闭，等同无选区时按 Esc） |

**标注说明**：标注以选区归一化坐标存储，**移动/缩放选区时标注自动跟随**；识别、复制、贴图、提取信息时标注都会烧录进图片。绘制中工具条保持可见便于连续绘制；右键或 `Esc` 先退回选择模式（防误触退出截图）；点选区外重新框选时旧选区上的标注一并作废。框选及矩形 / 椭圆 / 箭头标注时光标为十字（画笔为笔形光标），便于精确对位。

**侧边迷你识别窗（默认识别方式）**：确认选区后**不再直接弹出大窗口**——屏幕右侧中部出现一个小胶囊（含截图缩略图），识别在后台进行，期间可继续手头的工作；连续多次识别时，胶囊在右侧**按创建顺序上下排列**（某个收起后其余自动补位），截图选区期间临时隐藏、结束后恢复：

| 胶囊状态 / 操作 | 作用 |
| --- | --- |
| 识别中 | 旋转圆角进度 + 已进行秒数；左键点击可提前展开完整结果窗（完成后结果同步回填） |
| 识别完成（自动） | 结果自动进剪贴板 + 托盘气泡提示；胶囊变绿 ✓ 显示结果首行，**保持显示直到手动点 × 关闭** |
| 悬停胶囊 | 弹出**放大预览**浮窗，查看本次识别的输入截图（移开即消失） |
| 「复制」按钮 | 把识别结果再复制一次到剪贴板（中途剪贴板被占用时用），按钮短暂显示「已复制✓」；胶囊不关闭 |
| 「编辑」按钮 | 展开完整结果窗口：查看 / 编辑 / 复制 / 渲染预览 / 贴到桌面（点胶囊本体等同「编辑」）；胶囊不关闭，结果窗内点「重试 / 提取」时胶囊会同步显示识别中 → 完成/失败 |
| 右上角 `×` | 关闭胶囊并移出队列（识别中点 × 则该次识别转入后台，完成后仍自动复制并气泡提示）；识别失败时同样提供 ×。右键胶囊不执行任何操作（防误关） |
| 识别失败 | 胶囊变红显示错误首行并保持；左键点开结果窗可重试 |
| 按住拖动 | 临时移动胶囊位置（下次重排时回到右侧队列） |

**贴图到桌面**：在工具条点「贴图」或在结果窗口点「贴到桌面」，把截图贴在屏幕任意位置对照原图——

| 贴图操作 | 作用 |
| --- | --- |
| 按住拖动 | 移动贴图 |
| 滚轮 | 以光标为中心缩放（5%–1600%） |
| 双击 | 复制图片到剪贴板并关闭 |
| `Esc` / 右键菜单 | 关闭；右键可 **识别公式 / 提取图片信息** / 复制 / 另存为 PNG / 重置 100% |

**贴图上直接识别**：右键贴图选「识别公式」或「提取图片信息」，会用当前配置的模型对贴图内容发起识别/提取，同样走侧边迷你窗流程（完成后自动复制，点开迷你窗查看/编辑；贴图保留在桌面，可继续缩放查看或对其它贴图重复操作）。文字贴图同样支持——识别的是渲染前的原文所对应的整张文字图。

结果窗口左上角的截图缩略图同样支持滚轮缩放、拖动平移，双击在「100%」与「适应窗口」间切换。

## 快速开始

Windows 有两条启动路径：

- **`start.cmd`（推荐）**：双击启动；会按「项目内 `.venv` → 本机已就绪的公式快截环境 → 自动建 `.venv` 并装依赖」的顺序找运行环境，已装过则**秒开**。支持子命令：`start.cmd console`（前台运行看日志）、`start.cmd selftest`（跑冒烟自测）、`start.cmd install`（补装/更新依赖，可重入）。脚本为纯 ASCII + CRLF 编码（保障任意中文/英文 Windows 下 cmd 解析正常），控制台提示为英文，程序界面为中文。
- **`run.bat`（全新机器）**：双击自动建虚拟环境、装依赖并启动。

或手动：

```bash
python -m pip install -r requirements.txt
python main.py
```

在**托盘菜单 →「设置…」**打开设置窗口，填写模型接入信息：

| 字段 | 含义 | 示例 |
| --- | --- | --- |
| `base_url` | OpenAI 兼容服务根地址 | `https://api.openai.com/v1` |
| `api_key` | 你的密钥 | `sk-...` |
| `model` | **支持图像的视觉模型** | `gpt-4o-mini` / `qwen-vl-max` / `glm-4v-flash` |
| 自定义提示词 | 决定模型怎么识别、输出什么 | 见下文 |

设置窗口内填 API 地址、Key、协议与代理，填完后点 **「测试连接」** 验证。

**获取可用模型**：填好 API 地址与 Key 后，点模型输入框旁的 **「获取模型列表」**，程序会请求 `GET {base_url}/models`（OpenAI / Anthropic 协议均兼容，走同一代理配置），把该服务所有可用模型拉进下拉框供选择——注意需挑选**支持图像输入（多模态视觉）**的模型。

**API 协议**（三选一）：

| 协议 | 适用服务 | 请求端点 | 鉴权方式 |
| --- | --- | --- | --- |
| OpenAI 兼容（默认） | OpenAI、通义、智谱、硅基流动、DeepSeek、opencode zen、Ollama 等 | `{base_url}/chat/completions` | `Authorization: Bearer` |
| OpenAI Responses | OpenAI 新版 Responses API 或兼容服务 | `{base_url}/responses` | `Authorization: Bearer` |
| Anthropic | Claude 官方或兼容 `/v1/messages` 协议的中转服务 | `{base_url}/v1/messages` | `x-api-key` 头 |

**LaTeX 输出格式**（设置窗口内可配，自动注入提示词末尾、优先级最高）：

| 公式包裹格式 | 说明 |
| --- | --- |
| ` ```latex ` 代码块（默认） | Typora / Overleaf / 大部分 Markdown 编辑器通用 |
| `$$...$$` | 美元双符号，Markdown 数学扩展常用 |
| `\[...\]` | 标准 LaTeX 行间公式定界符 |
| `\(...\)` | 圆括号行内 LaTeX 定界符 |
| `$...$` | 行内风格，每公式独立一行 |

**多行公式处理**：`逐行分段输出`（默认，多段独立公式）或 `align 对齐环境`（多行合并进一个 align，`&` 对齐、`\\` 换行，适合直接粘贴进论文）。

**保留定界符**（默认勾选）：复制 LaTeX 时按所选包裹格式保留定界符原样输出。例如选择 `\(...\)` 时，剪贴板里就是 `\(\log \pi_\theta(y|x) = \sum_{t} \log \pi_\theta(y_t|x, y_{<t})\)` 这样带 `\(` `\)` 的完整文本；不勾选则只复制裸 LaTeX（`E=mc^2`）。``` 代码块格式始终剥掉围栏返回裸代码。公式渲染预览会自动剥掉定界符，不受此开关影响。

**携带原文输出**（默认关闭）：勾选后输出截图中的**完整原文**——普通文字按原样保留，数学公式按所选包裹格式（如 `\(...\)`）嵌在原位置，保持截图中的阅读顺序与分段，适合识别整段文字笔记。此模式下识别完成自动复制的是整段混排原文；渲染预览仍取文中第一个公式。

两种格式设置都会以「输出格式（优先于提示词中的任何格式描述）」的形式追加到你的自定义提示词末尾，改设置即生效、无需手改提示词。

**网络代理**：

| 填法 | 行为 |
| --- | --- |
| 留空 | 跟随系统代理环境变量（HTTP_PROXY 等） |
| `direct` | 强制直连，忽略系统代理（网络代理软件干扰时用这个） |
| `http://127.0.0.1:7890` 等地址 | 走指定代理 |

> 💡 排查连接问题：先用「测试连接」；若报 HTTP 4xx/5xx 说明网络已通、是服务端/模型/Key 的问题（如模型名不存在、模型故障）；若报网络错误/代理错误，尝试切换代理模式（留空 ↔ `direct`）。模型名可通过 `GET {base_url}/models` 查询。

> ⚠️ 配置保存在 `~/.formulasnip/config.json`（明文），请妥善保管你的 Key。

启动后**不弹任何窗口**（同 Snipaste 的安静常驻）：程序无主窗口，常驻**系统托盘**。正常表现：启动成功会弹出托盘气泡「已在后台运行：按 F1…」，任务栏时钟旁（可能需要点 `^` 展开）出现积分号图标，按 **F1** 立即出现全屏选区。模型配置从**托盘菜单 →「设置…」**进入；或直接按热键框选后按提示配置。
>
> 若以上一个都没有（无气泡、无图标、按 F1 无反应），说明进程没有正常起来。请运行 **`start.cmd console`** 在前台启动看报错，或直接打开日志 **`~/.formulasnip/app.log`**（启动每个关键节点都会写入），把内容发来即可定位。

### 使用逻辑（业务流程约定）

- **按热键 → 直接全屏选区**：无论是否已配置模型，按 F1（或备用键）第一反应都是进入截图，绝不被设置窗打断。
- **识别收纳到侧边迷你窗**：确认选区后识别在后台进行，屏幕侧边只出现一个小胶囊，不打断当前工作；完成后自动复制 + 气泡提示，需要查看/编辑时点一下胶囊即可展开完整结果窗（识别中点开也可以，完成后结果会同步回填）。
- **未配置模型不丢截图**：确认选区后若模型未配置，截图会被**暂存**；设置保存成功后**自动继续识别**这张图。取消配置则明确告知放弃，不留隐形状态。
- **识别完成自动复制**：LaTeX 自动进入剪贴板，直接 `Ctrl+V` 粘贴即可；在窗口里手动编辑后可再点「复制 LaTeX」。
- **失败可重试**：识别失败时胶囊保持显示，点开结果窗后点「重试」，自动采用**最新**的配置与提示词（改完设置无需重新截图）。
- **提取图片信息**（结果窗口按钮）：点「提取图片信息」会把同一张截图重新发给视觉模型，用内置提取提示词把图中全部信息——逐字转录的文字、`\(...\)` 包裹的公式、Markdown 表格、图表类型与关键数据、界面布局——整理成结构化 Markdown 并自动复制。把这段文本粘贴给**没有视觉能力的模型**（如 DeepSeek Chat 等纯文本模型），它们就能基于图中的内容继续问答，相当于给它们外挂了一双"眼睛"。提取结果可手动编辑后再复制。
- **收起不丢结果**：识别期间关闭结果窗口或右键收起迷你窗，完成后仍会自动复制，并通过托盘气泡告知结果。

### 自定义提示词（核心玩法）

内置默认提示词只描述识别行为，不含任何输出格式描述——格式（包裹定界符 / 多行 / 携带原文）全部由上方「LaTeX 输出格式」设置注入末尾并优先生效，两边不会打架。改乱了随时点提示词输入框旁的 **「恢复默认提示词」** 一键还原。改成别的就能换用途，例如：

```text
你是解题助手。请识别截图中的题目（文字+公式），先用简洁中文解释思路，
再给出完整解答过程，公式部分用 ```latex 代码块输出。
```

```text
请把截图中的手写公式转为规范的 LaTeX（补充缺失的括号与乘号），
只输出公式本身，用 ```latex 包裹，不要解释。
```

## 借鉴 Snipaste 的技术栈对照

Snipaste 是 **C++ / Qt** 编写的桌面截图工具。本项目用 **Python + PySide6（Qt 官方 Python 绑定）** 复刻其核心交互链路，抓屏与窗口体系同属 Qt 图形栈，便于快速改造成「截图 + 模型」工作流。

| 能力 | Snipaste（原生） | FormulaSnip（本 MVP） |
| --- | --- | --- |
| GUI 框架 | Qt（C++） | PySide6 / Qt6（Python） |
| 触发方式 | 全局热键 F1 | Windows `RegisterHotKey` + Qt 事件过滤器（同款思路） |
| 抓屏 | 逐屏抓取 / 虚拟桌面 | `QScreen::grabWindow` 逐屏抓取拼接，统一 DPI 支持多屏；混合 DPI 自动回退主屏 |
| 选区交互 | 拖拽 / 缩放 / 移动 / 十字光标 / 放大镜 | 拖拽 + 四边四角缩放 + 整框移动 + 方向键微调 + 尺寸浮标 |
| 选区工具条 | 松手后浮现（复制 / 保存 / 贴图…） | 松手后右下角浮现：识别公式 / 复制 / 贴图 / ✕ |
| 贴图 | F3 贴图、标注 | 结果窗「贴到桌面」：拖动 / 滚轮缩放 / 双击复制并关闭 / 右键菜单 |
| 常驻 | 系统托盘 | 系统托盘 |
| 选区确认 | 回车 / 双击 / 右键 | 回车 / 双击 / Esc 取消 |
| 后期处理 | 贴图、标注 | 调用「你自己的视觉模型」识别并输出公式（LaTeX） |

> 取舍说明：Python 版胜在接入模型 API 与改造成本低（十几行就能换一家模型、改一种用途）；代价是性能上限低于原生 C++，但对「框选一个区域 → 调一次 API」的场景完全够用。

## 已知限制

- **需要支持图像的视觉模型**：普通纯文本模型（如 DeepSeek Chat）无法识别图片，会返回 4xx/说明性错误，请换用多模态模型。
- **多屏**：各屏 DPI 一致时支持整块虚拟桌面框选；混合 DPI（如外接屏缩放与主屏不同）会自动回退到只截主屏。
- **大图识别容错**：全尺寸请求若读超时或服务端报 413（图片过大），会自动把图片最长边压缩一半重试一次；连接被拒 / 鉴权失败等错误不重试、直接报错以便诊断。超时拆分为连接 20 秒 + 读取为所设超时。
- **深度思考**：设置 → 高级参数可开启推理模式，按协议自动发送对应参数（OpenAI 兼容 `enable_thinking=true`；Responses `reasoning.effort=medium`；Anthropic `thinking.type=enabled`，预算为 max_tokens 的一半且 temperature 强制为 1）。响应更慢更费 token，普通公式识别建议关闭。
- **渲染预览**：依赖 `matplotlib`（未安装时只是预览按钮置灰），且其 math 渲染仅支持常用宏（`\frac` `\sqrt` `\sum` `\int`…），复杂环境（`\begin{aligned}` 等）建议直接使用复制出的 LaTeX 文本。
- **平台**：F1 全局热键为 Windows 实现；macOS/Linux 下请用托盘菜单触发截图。
- 识别中直接退出程序会等待当前请求结束（最长为你设置的请求超时），保证线程安全收尾。

## 常见问题

- **HTTP 400 / 图片不被支持**：确认所选模型是视觉模型；部分服务对图片体积敏感，程序已自动压缩到 1600px 内。
- **F1 没反应**：可能被其它软件占用（QQ/输入法等）。看托盘气泡提示，改用托盘菜单「截图识别」。
- **识别不准**：调整你的提示词（补一句“印刷体/手写体、严格输出 LaTeX、不要解释”），或换更强视觉模型。
- **想换用途**（识别图表、UI、代码截图）：直接改设置里的自定义提示词即可，无需改代码。
